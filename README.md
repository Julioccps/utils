# Utils

Due to some things in life, mostly work, I am having to use Windows.
So I decided to implement some utilities from GNU/Linux that don't have
a built-in alternative on Windows.

## What Exactly?

* [x] `yes` - that little thing that repeats what you told it;
* [x] `seq` - prints sequences of numbers;
* [ ] `tac` - `cat`, but with lines in reverse order;
* [ ] `rev` - reverses each line;
* [x] `true` / `false` - only set the exit status;
* [x] `sleep` - Unix-style sleep;
* [ ] `tee` - stdin -> stdout & a file;
* [ ] `head` - first N lines;
* [ ] `tail` - last N lines;
* [ ] `wc` - lines/words/bytes;
* [x] `printf` - prints formatted strings;
* [ ] `strings` - extracts printable strings from binaries;
* [ ] `hexdump` / `xxd` - hex dumps files;
* [ ] `file` - identifies files from magic numbers;
* [ ] `du` - recursive disk usage;
* [x] `man` - manual for each one before (which I'll have to write too);
